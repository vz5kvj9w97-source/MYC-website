# Mastery Yard Co website

Bilingual (English / Arabic) one-page site for Mastery Yard Co, served by GitHub Pages at www.mycksa.com.

- `index.html`: the whole page. Text appears twice, marked `data-l="en"` and `data-l="ar"`; the language button switches between them. Link to `#ar` to open in Arabic.
- `img/`: logo, photos and club crests taken from the company profile.
- `CNAME`: the custom domain for GitHub Pages.
